# OpenRAM SRAM Integration in Wildcat (Caravel Tapeout Project)

Célien Abbet, Amaury Chevoir, Aldric Rüedi 

This project focuses on integrating a dense SRAM macro generated with OpenRAM into the Wildcat RISC-V processor, targeting a full ASIC flow using the Caravel framework and the Sky130 PDK.

The initial motivation was to replace the existing `SyncReadMem`-based memory used in the Wildcat design. 
While convenient at the RTL level, such memories are synthesized into flip-flops and multiplexers, leading to extremely inefficient area usage and unrealistic implementations for ASIC tapeout.

The goal is therefore to:
- Replace this memory with a compact SRAM macro generated by OpenRAM
- Integrate it into the Wildcat processor
- Harden the design using the LibreLane/OpenLane flow
- Prepare a design suitable for real tapeout

While the project initially appeared straightforward, integrating OpenRAM turned out to be one of the most challenging parts of the entire flow. 
Significant effort was required to handle memory generation, macro integration, and physical design constraints. 
We ended up integrating a memory already generated and tested, available in the PDK. You can read about the details [here](open_ram_integration.md).
